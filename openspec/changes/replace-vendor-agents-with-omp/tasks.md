- [x] 2.9 Gate Outbox readiness on established provenance so a Session without it is never available for delivery; verify with a test that `outboxDeliveryPolicy` refuses such a Session and that the queued message stays queued rather than being dropped.
- [x] 2.10 Cancel any `extension_ui_request` with `method: "input"` that omp raises during a login without collecting input, and report the provider as needing a login in omp's own interface under the `magentic` profile; verify with a replay of `core/testdata/omp/login-secret-input.ndjson` that the request is cancelled, nothing is collected, and the outcome names provider and profile.
- [x] 2.11 Spike the protocol facts design.md lists as documented but unexercised — the lifecycle events including `agent_end.isTerminal`, `prompt_result.agentInvoked`, the control commands, prompt-delivery acknowledgement, and that approval requests arrive as `extension_ui_request` with a `confirm` method — against the installed omp; verify by recording the observed frames as fixtures under `core/testdata/omp/` and by amending design.md's Context to move each confirmed fact into the exercised list or to state what omp actually does instead. **Sections 3, 4, 5 and 6 depend on this**: a fact this spike contradicts changes those specs before their tasks are built.
- [x] 2.12 Keep a Session's process running when every interface closes, and keep it owned by the daemon rather than by the interface that created it; verify with a test that closing all clients leaves the host reachable and the Session running.
- [x] 2.13 Use the Session's own working directory, including a worktree, as the omp process's working directory with no substitution; verify with a test asserting the `--cwd` argument equals the Session's recorded working directory for both a plain Project and a worktree.
