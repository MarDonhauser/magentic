## 1. Product purpose

Magentic gives one developer a persistent control center for coordinating concurrent coding-agent work across local projects and sessions.

## 2. Primary user

An individual developer supervising several coding agents and repositories from the macOS desktop throughout the workday.

## 3. Principles

1. **Attention before administration.** The next action needed from the developer must be immediately visible and actionable.
2. **Persistent work, continuous context.** Sessions and repository context survive interface changes and interruptions.
3. **Fast by default.** Frequent monitoring and management actions minimize waiting and interaction cost.
4. **Multiple paths, equal competence.** Pointer and keyboard workflows are both first-class.

## 4. Success metric for the surface

The developer can understand why a session needs attention and choose the appropriate response without opening the main window.

## 5. Out of scope

- Does not replace the full session terminal.
- Does not present historical session context.
- Does not require keyboard shortcuts to complete an action.

## 6. Learned constraints

- **2026-09-01** — Notch overlay content begins below the physical display notch while the container remains visually attached to, and expands downward from, the notch. *Why:* the hardware notch otherwise obscures the title and detail needed to make the decision.
